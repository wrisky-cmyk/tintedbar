# 完整参考

本页收录 IPC 全量命令、键盘操作、栏上交互、状态图标细节、设置面板和可手改的配置文件。

## IPC（键位自行绑定）

面板开合统一走 IPC（`quickshell` 可简写为 `qs`），按键留给合成器，例如绑定到 `Super+Space`：

```sh
quickshell ipc call launcher toggle     # 启动器（还支持 open / close）
quickshell ipc call clips toggle        # 剪贴板面板（还支持 open / close）
quickshell ipc call powermenu toggle    # 电源菜单（还支持 open / close）
quickshell ipc call settings toggle     # 设置面板（还支持 open / close）
quickshell ipc call calendar toggle     # 时钟日历弹窗（仅 toggle）
quickshell ipc call weather toggle      # 天气面板（还支持 close）
quickshell ipc call notify toggle       # 通知历史面板（还支持 close）
quickshell ipc call tray list           # 托盘项清单：id / 是否有菜单 / 标题
quickshell ipc call tray menu           # 打开第一个带菜单的托盘项
quickshell ipc call tray menuOf <id>    # 打开指定程序的菜单（先用 list 获取 id）
quickshell ipc call tray next           # 切换到下一个带菜单的托盘项（循环），一键遍历所有程序
quickshell ipc call lock toggle         # 上锁（lock 与 toggle 同义）
quickshell ipc call wallpaper reload    # 重新读取壁纸映射
quickshell ipc call bt toggle           # 切换蓝牙电源（与栏上蓝牙图标右键相同）
quickshell ipc call audio mute          # 切换默认输出静音（与音量图标右键相同）
quickshell ipc call net toggle          # 兜底：断开/接回**当前使用的链路**（有线优先）
quickshell ipc call net wifi            # 仅操作无线格：已连接则关闭射频，射频关闭则重新开启
quickshell ipc call net wired           # 仅操作有线格：已连接则断开，断开则接回
quickshell ipc call brightness state        # 查询亮度状态（backend / percent）
quickshell ipc call brightness set <0-100>  # 设置亮度
quickshell ipc call brightness step <±N>    # 亮度步进
quickshell ipc call brightness preview 1|0  # 强制渲染开关（临时预览，重载即回）
quickshell ipc call debug on|off|state      # 运行中开关调试日志总闸（QS_DEBUG 的热替；进程级，不持久化）
```

多屏时，launcher / clips / powermenu / settings / calendar / weather / tray / brightness 作用于**聚焦屏**；
lock / wallpaper / bt 则是全局的。

记不清命令时运行 `quickshell ipc show`（列出所有 target 与子命令）。脚本中还可以使用
`ipc wait` / `ipc listen`（等待一次 / 持续监听信号）和 `ipc prop`（读写属性）。

## 键盘操作

面板**不抢占全局键位**，但每个面板都支持全键盘操作：从合成器绑定一条 IPC 键唤出面板，
其余交给方向键。

| 面板 | 键 |
| --- | --- |
| 启动器 | 输入即过滤 · ↑↓ 选择 · 回车启动（算式则复制结果） · Esc 关闭 |
| 剪贴板 | 输入过滤 · ↑↓ 选择 · 回车粘贴并关闭 · Esc 关闭（头部按钮见下） |
| 电源菜单 | `l` 锁屏 · `e` 注销 · `u` 挂起（仅发行版） · `h` 休眠 · `s` 关机 · `r` 重启；Esc 关闭 |
| 设置面板 | ↑↓ 换行（左栏走完接右栏） · ←→ 调值（开关直接切换 / 步进按各自格子 / 语言切下一项） · 回车执行 · Esc 关闭 |
| 通知历史 | ↑↓ 选择 · 回车直达（等同点击该条） · Delete 删除该条 · Esc 关闭（头部按钮见下） |
| 日历 | ←→ 翻月 · Esc 关闭 |
| 天气 | Esc 关闭 |
| 托盘菜单 | `tray menu` 打开第一个带菜单的项，`tray menuOf <id>` 指定程序；打开后是普通菜单：↑↓ 移动，回车/→ 进入子项，Esc 关闭 |
| 锁屏 / 授权弹窗 | 输入密码后回车确认（锁屏 Esc 清空重置）；授权弹窗 Esc = 取消 |

**列表头部的按钮**：剪贴板有两颗——“显示”条数步进（←→ 调节）和“清空”（回车执行）；
通知历史只有一颗“全部删除”。持续按 ↑ 离开列表会进入这些按钮；列表为空时整块隐藏，
键盘也不会移过去。

鼠标操作完全不受影响：键盘选中与鼠标悬停共用同一条高亮底色。

### 状态图标细节

蓝牙图标通常始终显示，只有系统没有蓝牙控制器时才整块消失。开启时画正常字形，关闭时画暗灰、
带斜线的“蓝牙关”；两种状态下都能点开 blueman-manager。

网络按硬件分格，把“硬件是否存在”和“是否已连接”分开显示：**已连接才亮，断开时画暗灰、
带斜线的“关”字形**。无线格已连接时显示信号扇形（弧线随信号强弱变化），未连接时（无论射频开关）
显示暗色“无线关”。有线格**仅在网线插入时出现**：已连接显示网口字形，插着但未连上显示暗色
“网线断开”，**拔线后整格消失**（插回自动恢复）。仅当机器**没有无线网卡**时，拔线才保留
“网线断开”字形；一块网卡都没有时，才只显示交叉的“断网”字形。

隐私指示（麦克风红点 / 屏幕共享橙点）**默认开启**，仅在应用使用麦克风或共享屏幕时出现在蓝牙右侧，
其余时间整块隐藏。它与**电池**是仅有的两个默认开启模块（笔记本默认显示电池，台式机无电池
自然不出现）。关闭后，每 2 秒扫描一次占用情况的定时器也会停止。麦克风图标的交互（V26.10.24
加）：**左键**弹出输入音量小滑条（优先控制占用流实际连接的输入源，多条流时优先默认源；
拖动松手提交、滚轮 ±5%，拖到 >0 会顺手解除静音）；**右键**切换静音——静音时图标换成带斜杠
的字形并压暗，占用仍在但已静音一眼可辨。混音器的电平监视流和蓝牙内部采集流不算应用占用。
屏幕共享图标暂无点击动作。

**重启提示**（在设置面板中开启，默认关闭）只在升级尚未生效时出现在**设置面板图标齿轮左侧**。判断以
**开机时间**（`/proc/stat` 的 btime）为基准，命中任一条即提示：`/boot` 内核镜像比开机时间新；
该内核的第三方 / dkms 模块重新编译过；合成器仍在使用已被替换的 `/usr` 用户态库（至少需要重登）。
它不区分发行版和内核包名，无需 root，也无需 pacman hook。点击后弹出一条通知：标题说明
“该重启了 / 该重新登录了”，正文按类别列出改动数量，带“现在重启”按钮，卡片 5 秒后自动收起。
开启时约每小时 130 毫秒 CPU（每 5 分钟检查一次，每次约 11 毫秒），关闭后完全停止；
读不到 `/boot` 或 `/proc` 时静默隐藏，不报错。

## 设置面板（齿轮）

**左栏**包含三组：

- **通用**：语言（跟随系统 / 中文 / English）、**配色**、栏宽、**24 小时制**（默认开启；12 小时制时
  中文显示“上午3:05”式前缀，英文显示“3:05 AM”式后缀），以及“栏上细节”开关：网速 / SSID、
  蓝牙设备、时钟带秒、农历/节日，均默认关闭。**SSID** 一个开关同时管理无线 SSID 与有线网卡名
  （`enp6s0`）；农历/节日还管理日历面板底部的历法资料（农历/干支/月相/节气，仅中文界面显示）。
- **锁屏与息屏**：禁止锁屏与息屏、**全屏禁止锁屏与息屏**、自动锁屏（分钟）、自动息屏（分钟）。
  前两条是同一件事的两面（手动 / 全屏时自动），均默认关闭；后两条默认 5 / 10，填 0 关闭。
  “全屏”指**真全屏**（最大化不算），判定读取合成器权威值，见
  `Compositor.fullscreenActive`。
- **通知**：勿扰模式、全屏免打扰（默认开启：全屏时通知只静默进入历史，不弹窗）、保留条数（5~50）。
  弹出通知恰好有一颗动作胶囊时，右侧会补一颗“忽略”，点击即关闭该通知（仍记入历史）。

**右栏**是模块开关：终端 / 浏览器 / 文件管理器 / CPU 温度 / 磁盘占用 / CPU 占用 / 内存占用 /
天气 / 正在播放 / 电源模式 / 隐私 / 剪贴板 / **重启提示** / 亮度 / 电池 / Num-Caps / 键盘布局，默认全关
（例外：隐私保护、笔记本电池默认开）。点开即上栏，关闭即消失，顺序大致对应栏上从左到右的排列；
最下方的只读**版本**见[版本与指纹](advanced.md#版本与指纹)，点击或回车会用浏览器打开项目仓库
（https://github.com/wrisky-cmyk/tintedbar），设置面板同时收起。

设置保存在 `~/.local/state/quickshell/bar-settings.json`，**由程序写入，请勿手改**；
剪贴板显示条数在剪贴板面板顶行调整。

几个抑制开关的分工：栏上的**满杯**控制“现在是否抑制”（开启时不会自动锁屏）；设置中的
**禁止锁屏与息屏**控制这颗图标是否存在（关闭后图标消失，并强制不抑制）；**全屏禁止锁屏与息屏**
独立生效，只在聚焦窗口处于真全屏时（看片、玩游戏，最大化不算）自动抑制，与图标无关。

## 可手改的配置文件

| 文件 | 用途 |
| --- | --- |
| `weather.conf` | 天气坐标 `lat=` / `lon=`；留空则整个天气模块隐藏（发布包默认留空） |
| `wallpapers.conf` | 壁纸映射，每行 `输出名=图片路径` 或 `输出名=#RRGGBB`（纯色）；图片可以放在任意目录，写绝对路径或 `~` 开头的路径。`*` 为兜底，需要其他填法时写 `路径\|contain`（或 `\|tile`）。修改后即时生效，也可以执行 `quickshell ipc call wallpaper reload` |
| `components/Style.qml` 顶部 | 两个字体名与栏高**默认值**（栏高平时在设置面板中调整，存档中的值优先）。颜色**不必改这里**：每个角色都实时读取当前 GTK 主题的 `gtk-3.0/gtk-dark.css`（会跟随 `@import`、解析 `@define-color` 别名，Breeze 这类第三方主题也支持）。想换色就换 GTK 主题，或只在设置面板“配色”中选择家族 |
| `scripts/theme-apply.sh` / `theme-toggle.sh` / `theme-css.sh` | 深浅色的落地逻辑，**平时无需手动运行**（栏上的深浅按钮、系统 color-scheme 被其他程序修改、nwg-look 改动主题时都会自动调用）。`theme-apply.sh --mode` 打印当前生效的 `light` / `dark`；`theme-css.sh <主题名>` 是栏读取色板用的解析器（自动调用），也可以手动运行，查看它从主题中解析出的颜色 |

查询天气坐标：
`curl -sS "https://geocoding-api.open-meteo.com/v1/search?name=杭州&count=3&language=zh"`。

想用自己的壁纸：图片放在哪里都行，在 `wallpapers.conf` 中写它的绝对路径或 `~` 开头的路径即可，
例如 `*=~/Pictures/wall.jpg`（不配置图片则继续使用纯色）。

面板颜色、圆角等集中在 `components/Style.qml`，改一处即可全栏生效。配色默认**跟随当前 GTK 主题**
（`auto`）：栏底、卡片、悬停、文字和主色都从主题 CSS 的 `@define-color` 读取，换主题即跟着换，
无需改代码。想让栏切换到内置的 Tinted 家族色板，在设置面板“通用”中点击“配色”那行翻转
（`auto` → Tinted 家族 9 个）。此设置只影响**栏**，
桌面其他程序仍使用 GTK 主题；需要一起变化时用 nwg-look 更换主题。
